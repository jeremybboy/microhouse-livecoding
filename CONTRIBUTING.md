# Contributing

Open a pull request from a dedicated branch. Keep an existing comparison baseline intact and add new takes as separate runnable scores or presets. Include a brief, a cue or bar range, the musical variable being tested, and the checks you ran. Mark listening pending unless someone auditioned the take.

Run `npm ci` and `npm test` with Node 24. To preview the site locally, run `python3 -m http.server 8000 --directory docs` and open `http://localhost:8000/`. Use a separate Strudel tab to audition test files while another performance is running.

Contribute only source and material you have permission to publish. Keep external sample assets under their upstream terms. The repository owner reviews and merges pull requests.
